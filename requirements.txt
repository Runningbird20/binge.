# Project 3 requirements — binge.
#
# This repository is a Node.js / React / Express application (plus native
# Apple TV and Fire TV apps), not a Python app. There are no Python packages
# to install with pip; this file documents what the project needs and the
# commands to install, run and test it. Every line is a comment, so
# "pip install -r requirements.txt" is a harmless no-op.
#
# System requirements
# - Node.js 24.x (see "engines" in package.json) and the npm that ships with it
# - A Supabase project (accounts and user data) and a Neon Postgres database
#   (the movie / TV / book catalog); see docs/database-split.md
# - Optional: Xcode with the tvOS SDK (tv-apple/, deployment target tvOS 17),
#   JDK 17 + Android SDK 35 (tv-android/, Fire OS 5 / API 22 and up)
#
# Local environment (copy .env.example to .env; .env is gitignored)
# - REACT_APP_SUPABASE_URL and REACT_APP_SUPABASE_PUBLISHABLE_KEY (or _ANON_KEY): browser-safe, required
# - DATABASE_URL: Neon connection string for the catalog (/api/neon-data)
# - SUPABASE_URL and SUPABASE_SECRET_KEY (or SUPABASE_SERVICE_ROLE_KEY): server only, for admin features
# - REACT_APP_TMDB_API_KEY: artwork, trailers and browse rows
# - REACT_APP_ENABLE_LEGACY_BACKEND=true lets the frontend use the Express API
# - Optional: OMDB_API_KEY, GROQ_API_KEY, OPENSUBTITLES_API_KEY, VAPID_* and CRON_SECRET
#
# Install dependencies
#   npm install
#
# Run the full app locally (React on :3000, Express API on :5001)
#   npm start
#
# Run only the frontend / only the backend API
#   npm run start:client
#   npm run server
#
# Build for production (fails on any lint warning, like the Vercel build)
#   CI=true npm run build
#
# Run tests
#   CI=true npx react-scripts test --watchAll=false   # web unit tests, once
#   node --test server/data-access/*.test.js          # server tests
#   npm run test:e2e                                  # Playwright end-to-end tests
#   tv-apple/scripts/run-tests.sh                     # Apple TV unit tests (simulator)
#
# Optional catalog/data import commands (scripts in scripts/ and scripts/scrapers/)
#   npm run import:tmdb            # TMDB movies + TV
#   npm run import:openlibrary     # Open Library books
#   npm run import:goodreads       # Goodreads books
#   npm run import:books           # Internet Archive books
#   npm run import:plex            # Plex movies + TV
#   npm run import:malayalam       # every recent title in one language (TMDB)
#   npm run import:backfill-catalog
#
